# My Projects Portfolio

This repository contains three personal projects I developed while learning web development and computer science.

## 1. Tennis Event App

**Technologies:** React, TypeScript, Tailwind CSS

A web application for managing tennis event schedules. Features include event creation with input validation, a timeline view based on event start times and durations, event deletion, and print-friendly layouts.

## 2. Quiz App

**Technologies:** React, TypeScript, Tailwind CSS

A quiz application featuring multiple-choice questions, answer feedback, score tracking, and confirmation prompts before reviewing answers.

## 3. ToDo App

**Technologies:** HTML, CSS, JavaScript

A task management application that allows users to manage tasks and save them in local storage.

---

Each project is organized in its own folder. Please see the individual project folders for source code and setup instructions.
